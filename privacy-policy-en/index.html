Privacy Policy

Last updated: February 6, 2026

Introduction

This privacy policy describes how data is collected and processed while browsing this website.

Data Collected

This website uses Umami Analytics, a privacy-focused and open-source web analytics platform, to better understand how the site is used and to improve user experience.

Information Collected by Umami

Umami collects only anonymous and aggregated data:

  • Pages visited
  • Referrer (site you came from)
  • Browser and operating system
  • Device type (desktop, mobile, tablet)
  • Country of origin (based on IP address, which is immediately anonymized)
  • Visit duration

What We DO NOT Collect

  • Full IP addresses (they are anonymized)
  • Tracking cookies
  • Personally identifiable information
  • Sensitive data of any kind

Legal Basis for Processing

Data processing is based on legitimate interest (Art. 6, para. 1, lett. f GDPR) to understand site usage and improve its functionality and content.

Data Retention

Collected data is stored in anonymous form for a maximum period of 24 months, after which it is automatically deleted.

Data Sharing

Data is not sold, shared, or transferred to third parties. It remains exclusively on the server hosting Umami Analytics.

Your Rights

Under GDPR, you have the right to:

  • Request information about collected data
  • Request data deletion
  • Object to data processing

Since the data is completely anonymous, it is not possible to link statistics to specific individuals.

Changes to Privacy Policy

This privacy policy may be updated periodically. The last update date is indicated at the top of the page.
