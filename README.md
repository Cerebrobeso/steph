# Portfolio

Portfolio personale sviluppato con Angular 21, Spartan UI e Tailwind CSS con rendering SSR per ottimizzare SEO e performance.

## 🚀 Tecnologie

- **Angular 21** - Standalone components, signals, control flow moderno
- **SSR/Prerendering** - Server-side rendering per SEO e performance
- **Spartan UI** - Componenti UI (`@spartan-ng/helm`, `@ng-icons/lucide`)
- **Tailwind CSS** - Utility-first CSS framework
- **TypeScript** - Type-safe development
- **Geist Font** - Font moderno e leggibile
- **GitHub Pages** - Hosting statico gratuito
- **GitHub Actions** - CI/CD automatico per il deploy
